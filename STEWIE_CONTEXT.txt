## TECH STACK

Frontend:
- React 18 + TypeScript + Vite
- Tailwind CSS + shadcn/ui
- wagmi + viem (blockchain)

Backend:
- Firebase (Firestore, Auth, Storage)
- Netlify Functions (serverless)

Blockchain:
- Base (Coinbase L2)
- OnchainKit
- PlintOrders.sol smart contract

Payments:
- M-Pesa STK Push (Kenya)
- Crypto (USDC/ETH)

AI:
- OpenRouter (Llama 3.1 - free!)
- Fallback generation (works without API)
